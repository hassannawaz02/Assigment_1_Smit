# Assignment 01 — SMIT Agentic AI Course

This repository contains **Assignment 01** of the **Agentic AI** course from SMIT (Saylani Mass IT Training), covering the basic foundation of Python.

## 📄 File

| File | Description |
|------|-------------|
| `Assigment_01.py` | Takes the user's name, city, and favorite food, then prints an Introduction Card |

## 🐍 Python Concepts Used

This assignment uses the following basic concepts:

- **Variables** — `name`, `city`, `favorite_food`
- **`input()`** — Taking data from the user (runtime input)
- **`print()`** — Displaying output on the screen
- **String values** — Handling text data
- **Escape sequence** — Using `\n` (new line)

## ▶️ How to Run

```bash
python Assigment_01.py
```

### Example Output

```
Enter your name: Hassan Nawaz
Which city are you from? Karachi
What is your favorite food? Biryani

--- Introduction Card ---
Name: Hassan Nawaz

-------------------------
```

1. How to run a Python program
